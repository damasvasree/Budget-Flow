## 💰 Budget Flow

Budget Flow is a modern, full-stack personal finance and budget tracking web application designed to simplify wealth management, expense tracking, and financial planning. Built with **React**, **TypeScript**, **Tailwind CSS**, and **Supabase**, Budget Flow empowers users to monitor spending, set dynamic budgets, analyze income vs. expense analytics, and maintain financial clarity through a clean, intuitive interface.

The project demonstrates how modern web technologies and real-time database architectures can deliver a seamless, privacy-focused financial management platform.

---

## 🚀 Project Overview

Budget Flow provides a complete personal finance ecosystem to help individuals take full control of their money. 

Instead of dealing with complex spreadsheets or manual calculations, users can record daily transactions, set monthly category budgets, track recurring bills, run database migrations with Supabase, and visualize spending habits with interactive real-time analytics.

---

## ✨ Features

* 📊 **Interactive Dashboard:** High-level summary of total balance, income, expenses, and savings rate.
* 💸 **Transaction Tracking:** Easily log, categorize, and filter income and expense records.
* 🎯 **Budget Planning & Allocation:** Set category-based spending targets and receive real-time budget limit alerts.
* 📈 **Financial Analytics & Charts:** Visual breakdowns of spending patterns, monthly comparisons, and category distributions.
* 🗄️ **Supabase Integration:** Full database management with real-time sync and SQL migration support.
* 🔐 **User Authentication:** Secure signup and sign-in management for personalized finance tracking.
* ⚙️ **User Profile & Settings:** Customizable currency options, categories, and account configurations.
* 🌙 **Light/Dark Theme Support:** Seamless theme switching for a customized viewing experience.
* 📱 **Fully Responsive UI:** Crafted with Tailwind CSS for optimal viewing across mobile, tablet, and desktop devices.

## ⚙️ Installation & Setup

### Prerequisites

Ensure you have the following installed locally:
* [Node.js](https://nodejs.org/) (v18 or higher recommended)
* [Git](https://git-scm.com/)
* npm (comes bundled with Node.js)

### 1. Clone the Repository

```bash
git clone [https://github.com/damasvasree/budget-flow.git](https://github.com/damasvasree/budget-flow.git)
2. Navigate to Project Directory
Bash
cd budget-flow
3. Install Dependencies
Bash
npm install
4. Configure Environment Variables
Create a .env file in the root directory and add your Supabase credentials:

Code snippet
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
5. Start Development Server
Bash
npm run dev
Open your browser and navigate to http://localhost:5173.

🖥️ Usage
Launch the application locally or via production build.

Register or log in to your account.

Configure your monthly budget limits in the Settings or Budget module.

Add new financial transactions (Income/Expense) with amount, category, and date.

Track real-time progress on the Dashboard and view detailed breakdowns on the Analytics page.

Manage database updates via Supabase migrations when expanding backend schemas.
